# Origin and attribution

This repository continues the existing Git history of `rancher-host-local-ipam`. Historical commits show that its allocator and disk store were derived from the Container Network Interface project around upstream commit `7964385`, followed by project-specific lease reuse and metadata-driven orphan cleanup.

The historical README carried this notice, retained here for attribution:

> Copyright (c) 2014-2017 Rancher Labs, Inc.

PastureStack claims authorship only for its own changes. Existing commits, CNI Authors source headers, copyright notices, and Apache-2.0 terms remain attributable to their original authors. History may be filtered only if legal, privacy, or security review requires it; any old-to-new commit mapping must remain in the private migration knowledge base.
